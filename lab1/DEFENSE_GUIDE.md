## Что такое фильтр Собеля

Фильтр Собеля ищет границы объектов. Граница находится там, где яркость соседних пикселей резко изменяется.

Сначала изображение переводится в оттенки серого. Затем для каждого пикселя анализируется область `3 × 3` с помощью двух ядер.

Горизонтальная составляющая:

```text
-1  0  1
-2  0  2
-1  0  1
```

Вертикальная составляющая:

```text
-1 -2 -1
 0  0  0
 1  2  1
```

Первое ядро вычисляет `Gx`, второе — `Gy`. Общая величина градиента:

```text
G = √(Gx² + Gy²)
```

Чем больше `G`, тем сильнее изменение яркости и тем заметнее граница. Результат ограничивается диапазоном `0–255`.

## Что такое свёртка

Свёртка — это перемещение небольшой матрицы-ядра по изображению. Значения соседних пикселей умножаются на коэффициенты ядра и складываются. Полученное число записывается в выходное изображение.

## Библиотечная реализация

Функция `sobel_lib()`:

1. Загружает изображение в оттенках серого.
2. Вычисляет `Gx` и `Gy` через `cv2.Sobel`.
3. Объединяет их через `cv2.magnitude`.
4. Ограничивает значения функцией `np.clip`.
5. Приводит результат к `uint8` и сохраняет изображение.

Ключевые строки:

```python
gx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
mag = cv2.magnitude(gx, gy)
out = np.clip(mag, 0, 255).astype(np.uint8)
```

## Нативная реализация

Функция `sobel_native()`:

1. Открывает изображение через Pillow.
2. Переводит его в оттенки серого.
3. Перебирает внутренние пиксели двумя циклами.
4. Вручную рассчитывает `Gx` и `Gy` по соседям пикселя.
5. Вычисляет `√(Gx² + Gy²)`.
6. Ограничивает результат значением `255` и сохраняет его.

Циклы не обрабатывают крайние пиксели, потому что для ядра `3 × 3` нужны соседи со всех сторон.

## Сравнение скорости

Для измерения используется `time.perf_counter()`. Проверяются разрешения:

- `200 × 150`;
- `400 × 300`;
- `800 × 600`;
- `1280 × 720`.

Коэффициент ускорения:

```text
время нативной реализации / время OpenCV
```

OpenCV быстрее, потому что он реализован на оптимизированном C/C++, эффективнее работает с памятью и использует векторные инструкции процессора. Нативная версия выполняет много отдельных операций внутри циклов Python.

Обе реализации имеют сложность приблизительно `O(W × H)`, потому что обрабатывают все пиксели. OpenCV быстрее не из-за другой сложности, а из-за оптимизированной реализации.

## Частые вопросы

### Что такое оператор Собеля?

Алгоритм выделения границ, оценивающий изменение яркости изображения по двум направлениям.

### Что такое градиент?

Вектор, показывающий направление и величину наиболее быстрого изменения яркости.

### Зачем нужны `Gx` и `Gy`?

Они описывают изменение яркости по двум взаимно перпендикулярным направлениям.

### Почему используются два ядра?

Чтобы обнаруживать границы разной ориентации, а не только одного направления.

### Почему изображение переводится в оттенки серого?

Алгоритм анализирует яркость. В полутоновом изображении каждый пиксель представлен одним числом, поэтому обработка проще.

### Что делает `np.clip`?

Ограничивает значения диапазоном от `0` до `255`.

### Что такое `uint8`?

Восьмибитное целое число без знака, принимающее значения от `0` до `255`. Это стандартный формат значения яркости пикселя.

### Почему OpenCV быстрее?

Он использует скомпилированный и оптимизированный код, а не интерпретируемые циклы Python.

### Почему не обрабатываются крайние пиксели?

У них отсутствует часть соседей, необходимых для применения ядра `3 × 3`.

### Результаты полностью одинаковые?

Основные контуры визуально совпадают. Небольшие различия могут возникать из-за обработки границ и округления.

### Что находится на графике?

По горизонтали указано разрешение изображения, по вертикали — время выполнения. Отдельные столбцы показывают OpenCV и нативную реализацию.

Не стоит утверждать, что ускорение растёт экспоненциально. Достаточно сказать, что преимущество OpenCV остаётся значительным при увеличении разрешения.

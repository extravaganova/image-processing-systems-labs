## Видео для ЛР2

В папке [lab2](lab2/) находится демонстрационное видео `demo_input.mp4`. Оно содержит текстурированную карточку, которая перемещается и меняет перспективу. После запуска трекера получается видео `demo_tracked.mp4` с рамкой объекта.

```bash
cd lab2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python generate_demo.py
python track_object.py demo_input.mp4 demo_tracked.mp4 --roi 235,90,490,330
```

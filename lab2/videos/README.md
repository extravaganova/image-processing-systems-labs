# Видео для тестирования ЛР2

В папке собраны тестовые материалы:

- `test_mona_lisa.avi` — обычное движение объекта;
- `test_mona_lisa_blur.avi` — движение с размытием;
- `test_mona_lisa_blur_extra.avi` — более сложный вариант с размытием;
- `tracked_mona_lisa.mp4` — обработанный результат первого теста;
- `tracked_mona_lisa_blur.mp4` — обработанный результат второго теста;
- `tracked_mona_lisa_blur_extra.mp4` — обработанный результат третьего теста;
- `book_input.MOV` — самостоятельно записанное видео с книгой;
- `book_tracked.mp4` — результат обработки видео с книгой.

## 3. Теория

Ключевые точки — это характерные участки изображения: углы, пересечения линий, буквы и элементы текстуры.

В работе используется алгоритм ORB. Он находит ключевые точки и создаёт для них дескрипторы — числовое описание внешнего вида точки.

Затем программа сравнивает дескрипторы книги на первом кадре с дескрипторами на текущем кадре. Для сравнения используется BFMatcher и расстояние Хэмминга.

По найденным совпадениям вычисляется гомография с помощью RANSAC. Она позволяет учитывать перемещение, поворот, изменение масштаба и перспективный наклон книги. Поэтому рамка может быть наклонённым четырёхугольником.

## 4. Как работает программа

### Первый кадр

«Сначала программа читает первый кадр видео. Из него выделяется область книги — ROI. На этой области с помощью ORB находятся ключевые точки и создаются дескрипторы. Они становятся эталонным описанием объекта».

Показывать функцию `build_tracker` в файле `track_object.py`.

### Поиск объекта

«Для каждого следующего кадра программа снова находит ключевые точки. Затем сравнивает их с точками книги из первого кадра. Слабые совпадения удаляются с помощью ratio test».

Показывать функцию `locate_object`.

### Гомография

«Если хороших совпадений достаточно, программа вычисляет гомографию методом RANSAC. После этого координаты четырёх углов книги переводятся в текущий кадр».

Показывать строки с `cv2.findHomography` и `cv2.perspectiveTransform`.

### Рамка и подпись

«После определения положения книги программа рисует зелёную рамку и подпись `Object: tracked`. Если хороших совпадений недостаточно, программа выводит `Object: not found`».

Показывать функцию `draw_tracking_result`.

### Обработка видео

«Функция `track_video` последовательно читает все кадры, обрабатывает их и записывает результат в новый видеофайл».

Показывать функцию `track_video`.

## 5. Демонстрация запуска

Для демонстрационного видео используется команда:

```bash
python track_object.py demo_input.mp4 demo_tracked.mp4 --roi 235,90,490,330
```

Для собственного видео с книгой:

```bash
python track_object.py book.mp4 book_tracked.mp4 --roi x,y,ширина,высота
```

`book.mp4` — видео с книгой, а `book_tracked.mp4` — обработанный результат.

Если книга занимает почти весь первый кадр, можно запустить без ROI:

```bash
python track_object.py book.mp4 book_tracked.mp4
```

## 8. Возможные вопросы

### Почему выбрана книга?

Книга содержит много текстуры: буквы, линии и рисунки. Поэтому на ней легко найти ключевые точки.

### Что такое ROI?

ROI — это область интереса, то есть прямоугольная область первого кадра, в которой находится объект.

### Зачем нужна гомография?

Гомография переводит координаты объекта из первого кадра в текущий и учитывает перспективное искажение.

### Почему иногда объект не находится?

Причинами могут быть плохое освещение, размытие, сильное перекрытие книги или слишком малое количество совпадающих ключевых точек.
